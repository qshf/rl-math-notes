Ch8 vs Ch9 · 值函数近似与策略梯度易混对比

章节对比总结 · 参考 Ch8 笔记 / Ch9 笔记 / Ch8 地图 / Ch9 地图 / 统一符号表
总问题：第 8 章和第 9 章都把“表格”换成“参数化函数”，也都出现目标函数、梯度、状态分布和采样估计；最容易混的是：到底在学价值，还是在学策略？
一句话答案：Ch8 用参数 $w$ 拟合价值函数 $\hat v,\hat q$，样本信号主要是 TD error / Bellman target；Ch9 用参数 $\theta$ 直接优化策略 $\pi(a\mid s,\theta)$，样本信号是 log 概率梯度乘动作价值或回报。
Ch8
价值函数近似：先学会评价

把表格 $v(s)$、$q(s,a)$ 换成 $\hat v(s,w)$、$\hat q(s,a,w)$。

核心更新：让当前估计贴近 MC return、TD target 或 Bellman optimality target。

Ch9
策略梯度：直接学会行动

把表格策略 $\pi(a\mid s)$ 换成 $\pi(a\mid s,\theta)$。

核心更新：让整体指标 $J(\theta)$ 变大，沿 $\nabla_\theta J$ 做梯度上升。

1. 主线总表

维度Ch8 值函数近似Ch9 策略梯度最容易混的点
函数化对象 $\hat v(s,w)$ 或 $\hat q(s,a,w)$ $\pi(a\mid s,\theta)$ 都是函数近似，但一个输出“价值”，一个输出“动作概率”。
参数 $w$：value / critic 参数 $\theta$：policy / actor 参数 后面 Actor-Critic 会同时有 $w,\theta$，这里先分清角色。
目标 让价值估计贴近真值、TD target，或满足投影 Bellman 固定点 最大化策略表现 $J(\theta)$，如 $\bar v_\pi$ 或 $\bar r_\pi$ Ch8 常是“最小化误差”；Ch9 是“最大化回报指标”。
更新方向 梯度下降误差，或写成 $+\alpha\,\delta\nabla_w\hat v$ 的半梯度 TD 梯度上升：$\theta_{t+1}=\theta_t+\alpha\nabla_\theta J(\theta_t)$ 符号上都可能是加号，但含义不同：TD error 已经含有 target - prediction。
价值的作用 价值本身就是学习对象 $q_\pi(s,a)$ 是更新策略的评分信号 策略梯度不是“不需要价值”，而是价值服务于改策略。
代表算法 TD-Linear、LSTD、Sarsa-FA、Q-learning-FA、DQN Policy Gradient Theorem、REINFORCE DQN 属于 value-based；REINFORCE 属于 policy-based。

2. 符号对比表

符号Ch8 中的含义Ch9 中的含义速记
$w$ 价值函数参数：$\hat v(s,w)$、$\hat q(s,a,w)$ 本章通常不用作策略参数；到 Ch10 常作为 critic 参数 谁负责“打分”，谁多半用 $w$。
$\theta$ 通常不是本章主角 策略参数：$\pi(a\mid s,\theta)$ 谁负责“行动概率”，谁用 $\theta$。
$J(w)$ 误差目标，如 $\sum_s d_\pi(s)(v_\pi(s)-\hat v(s,w))^2$ 不是常用写法 Ch8 的 $J$ 多数是要最小化。
$J(\theta)$ 不是本章主角 策略表现指标，如 $\bar v_\pi,\bar r_\pi$ Ch9 的 $J$ 是要最大化。
$d_\pi$ 平稳分布，用来给价值误差加权；长期常访问状态更重要 平稳分布，可作为平均价值 / 平均奖励和策略梯度里的状态权重 同一个对象：当前策略长期把智能体带到哪里。
$\rho_\pi$ 不是 Ch8 主线符号 从 $d_0$ 出发的折扣状态访问分布；Theorem 9.2 用它 $d_0$ 是起点，$\rho_\pi$ 是折扣未来会经过哪里。
$\eta$ 不是 Ch8 主线符号 策略梯度定理里的统一状态权重占位符，可取 $\rho_\pi$ 或 $d_\pi$ 看到 $\eta$，先问当前 $J(\theta)$ 选的是哪个 metric。
$\delta_t$ TD error：target 减当前估计 REINFORCE 本章不用 TD error；Ch10 A2C 会把 $\delta_t$ 当 advantage 估计 Ch8 先把 $\delta$ 记成“价值学习的误差信号”。

3. 目标函数：都是 $J$，但一个降误差，一个升回报

问题Ch8 写法Ch9 写法读法
优化对象 $J_E(w)=\|\hat v(w)-v_\pi\|_D^2$ $J(\theta)=\bar v_\pi$ 或 $\bar r_\pi$ Ch8 问“估得准不准”；Ch9 问“这个策略好不好”。
是否依赖未知真值 真实 $v_\pi$ 通常未知，所以用 MC / TD target 替代 $q_\pi(s,a)$ 也未知，所以 REINFORCE 用 $G_t$ 估计 两章都在用样本替代不可直接看到的真值。
状态权重 $D=\operatorname{diag}(d_\pi)$：长期常访问状态误差权重大 $S\sim\eta$：状态按目标对应的分布加权 Ch8 的权重进误差；Ch9 的权重进梯度期望。
线性理论核心 TD-Linear 对应 projected Bellman fixed point：$\Phi w=MT_\pi(\Phi w)$ Policy gradient theorem：$\nabla_\theta J=\mathbb E[\nabla_\theta\ln\pi\,q_\pi]$ Ch8 的核心是 Bellman 自洽加投影；Ch9 的核心是把策略梯度写成可采样期望。
一个特别容易错的句子：“Ch8 最小化 $J(w)$，Ch9 也最小化 $J(\theta)$。”
更准确：Ch8 常把 $J(w)$ 当误差来最小化；Ch9 把 $J(\theta)$ 当策略表现来最大化，所以更新是梯度上升。

4. 更新公式并排看

算法 / 定理更新或梯度信号来自哪里一句话区分
TD-FA 状态值 $w_{t+1}=w_t+\alpha_t\delta_t\nabla_w\hat v(s_t,w_t)$ $\delta_t=r_{t+1}+\gamma\hat v(s_{t+1},w_t)-\hat v(s_t,w_t)$ 用一步 TD target 修价值函数。
Sarsa-FA $w\leftarrow w+\alpha\delta_t\nabla_w\hat q(s_t,a_t,w)$ $\delta_t=r+\gamma\hat q(s',a',w)-\hat q(s,a,w)$ 下一动作 $a'$ 是实际按当前策略采到的动作。
Q-learning-FA $w\leftarrow w+\alpha\delta_t\nabla_w\hat q(s_t,a_t,w)$ $\delta_t=r+\gamma\max_{a'}\hat q(s',a',w)-\hat q(s,a,w)$ 下一动作 $a'$ 是枚举后取最大，不是样本动作。
DQN $\min_w (y_T-\hat q(s,a,w))^2$ $y_T=r+\gamma\max_{a'}\hat q(s',a',w_T)$ 目标网络 $w_T$ 造标签，主网络 $w$ 被训练。
Policy Gradient Theorem $\nabla_\theta J(\theta)=\mathbb E[\nabla_\theta\ln\pi(A\mid S,\theta)q_\pi(S,A)]$ $q_\pi(S,A)$ 给动作打分，$\nabla\ln\pi$ 给改概率的方向 不是修价值，而是用价值信号改动作概率。
REINFORCE $\theta\leftarrow\theta+\alpha G_t\nabla_\theta\ln\pi(a_t\mid s_t,\theta)$ $G_t=\sum_{k=t+1}^{T}\gamma^{k-t-1}r_k$ 估计 $q_\pi(s_t,a_t)$ MC 版策略梯度：等后续回报来奖励/压低采样动作。

5. “target / error / gradient” 三件事不要串台

术语Ch8 里通常指Ch9 里通常指判断方法
target 用来拉近价值估计的标签：$r+\gamma\hat v$、$r+\gamma\max\hat q$、$y_T$ REINFORCE 不常叫 target；它用 $G_t$ 估计动作价值 如果公式是“target - prediction”，多半在 Ch8 价值学习。
TD error $\delta_t=\text{target}-\text{current estimate}$ 本章策略梯度主线不用 TD error 看到 $\delta_t\nabla_w\hat v$，先定位到价值函数参数更新。
gradient $\nabla_w\hat v$ 或 $\nabla_w\hat q$：价值输出对参数的敏感度 $\nabla_\theta\ln\pi$：被采样动作的 log 概率对策略参数的敏感度 对谁求导，就在改谁：$w$ 改价值，$\theta$ 改策略。
sample return MC 可用 $G_t$ 当价值标签，但 Ch8 主线强调 TD target REINFORCE 用 $G_t$ 当 $q_\pi(s_t,a_t)$ 的样本估计 同样是 $G_t$，在 Ch8 是监督标签，在 Ch9 是策略更新权重。

6. 状态分布：同样是“权重”，用途不同

分布定义 / 直觉Ch8 用法Ch9 用法
$d_0$ 初始状态分布：每局从哪里开始 不是 Ch8 主线 $\bar v_\pi^0=d_0^Tv_\pi$ 的起点权重
$d_\pi$ 平稳分布：策略跑久后经常待在哪里 $J(w)$、$D$、projected Bellman error 中给状态误差加权 $\bar v_\pi,\bar r_\pi$ 以及部分 policy gradient 公式中的状态权重
$\rho_\pi$ 折扣访问分布：从 $d_0$ 出发后，未来按 $\gamma^k$ 累计访问强度 不是 Ch8 主线 Theorem 9.2：目标从 $d_0$ 开始，梯度按 $\rho_\pi$ 加权
$\eta$ 状态权重的统一占位符 不是 Ch8 主线 $\nabla J=\sum_s\eta(s)\sum_a\nabla\pi(a\mid s)q_\pi(s,a)$
速记：$d_\pi$ 在 Ch8 里回答“哪些状态的价值误差更重要”；在 Ch9 里回答“梯度期望里哪些状态更常被算到”。同一个长期访问比例，进入了两个不同问题。

7. Bellman 路线 vs Log-Trick 路线

Ch8：Bellman / TD 路线

先有 Bellman 自洽：

$$v_\pi=T_\pi v_\pi,\qquad q_*=T_*q_*.$$

真实值不可见，就用样本 target：

$$\text{update}\propto(\text{Bellman target}-\text{current estimate})\nabla_w\hat v.$$

关键词：TD target、Bellman backup、projected Bellman error、semi-gradient。

Ch9：Policy Gradient 路线

先定义策略表现：

$$J(\theta)=\bar v_\pi\quad\text{or}\quad \bar r_\pi.$$

再用 log-trick 写成采样期望：

$$\nabla_\theta J=\mathbb E[\nabla_\theta\ln\pi(A\mid S,\theta)q_\pi(S,A)].$$

关键词：metric、score function、log-trick、REINFORCE。

8. 常见混淆点速查

#容易误以为正确辨析一句话记忆
1 Ch8、Ch9 都是 function approximation，所以学的是同一类东西 Ch8 函数化 value；Ch9 函数化 policy。 Ch8 学“怎么看”，Ch9 学“怎么做”。
2 $J(w)$ 和 $J(\theta)$ 都是 loss $J(w)$ 常是误差要降；$J(\theta)$ 是表现要升。 看变量，也看动词：minimize 还是 maximize。
3 策略梯度不需要价值函数 公式里仍有 $q_\pi(s,a)$；只是不先学出 $q$ 再 greedy。 价值从“主角”变成“评分器”。
4 REINFORCE 的 $G_t$ 和 TD target 是同一个东西 $G_t$ 是完整后续回报；TD target 是一步奖励加自举估计。 REINFORCE 等后账，TD 走一步就估。
5 DQN loss 为 0 就等于价值估计正确 只能说明 replay buffer 上的 Bellman/TD loss 小，不保证真实 value error 小。 拟合了靶子，不等于靶子就是真相。
6 log-trick 改变了优化目标 它只是恒等变形：$\nabla\pi=\pi\nabla\ln\pi$，方便把求和写成采样期望。 $\ln\pi$ 是采样化工具，不是新目标。
7 $d_0,d_\pi,\rho_\pi,\eta$ 都差不多 $d_0$ 是起点，$d_\pi$ 是长期比例，$\rho_\pi$ 是折扣访问强度，$\eta$ 是占位符。 先问“从哪里开始”，再问“按什么时间权重”。
8 Q-learning-FA 和 REINFORCE 都是 off-policy Q-learning/DQN 可 off-policy；REINFORCE 要按当前策略采样，通常是 on-policy。 REINFORCE 用自己的轨迹给自己调概率。

9. 一张最短公式卡

Ch8 value approximation
Ch9 policy gradient
易混公式集中
$$ \begin{aligned} \text{Ch8 TD-FA:}\quad &w_{t+1}=w_t+\alpha_t\delta_t\nabla_w\hat v(s_t,w_t),\\ &\delta_t=r_{t+1}+\gamma\hat v(s_{t+1},w_t)-\hat v(s_t,w_t).\\[4pt] \text{Ch8 DQN:}\quad &y_T=r+\gamma\max_{a'}\hat q(s',a',w_T),\qquad \min_w(y_T-\hat q(s,a,w))^2.\\[4pt] \text{Ch9 PG theorem:}\quad &\nabla_\theta J(\theta)= \mathbb E_{S\sim\eta,A\sim\pi} [\nabla_\theta\ln\pi(A\mid S,\theta)q_\pi(S,A)].\\[4pt] \text{Ch9 REINFORCE:}\quad &\theta\leftarrow\theta+\alpha G_t\nabla_\theta\ln\pi(a_t\mid s_t,\theta). \end{aligned} $$
核心洞见
第 8 章和第 9 章的相似处，是都把表格对象压进参数空间；真正的分叉，是参数更新的“误差信号”从哪来。Ch8 的信号来自 Bellman/TD：当前价值和目标价值差多少；Ch9 的信号来自 policy gradient：这个采样动作的概率该按它带来的回报往上推还是往下压。

上接 / 下启

上接 Ch7：TD 已经给出“用一步自举 target 学价值”的套路；Ch8 把这个套路搬到参数化价值函数。

下启 Ch10：Actor-Critic 会把两条线合起来：actor 用 $\theta$ 学策略，critic 用 $w$ 学价值；critic 给 actor 提供比 REINFORCE 的完整回报更低方差的更新信号。
