一条公式链

1. 从 MC 的样本平均出发：期望看不见，就拿样本平均。

$$\mu=\mathbb E[X],\qquad \bar x_k=\frac1k\sum_{i=1}^k x_i$$
$$\bar x_k=\bar x_{k-1}+\frac1k(x_k-\bar x_{k-1})$$
接下一步：这个式子已经有 TD 的影子：旧估计被新样本 target 拉一下。

2. Ch6 把样本平均抽象成随机近似母式。

$$w_{k+1}=w_k+\alpha_k(x_k-w_k)$$
$$w_{k+1}=w_k-\alpha_k\underbrace{(w_k-x_k)}_{\hat g(w_k)}$$
$$\underbrace{w_k-x_k}_{\hat g(w_k)} = \underbrace{(w_k-\mathbb E[X])}_{g(w_k)} + \underbrace{(\mathbb E[X]-x_k)}_{\eta_k}$$
读法：理想方向是 $g(w_k)=w_k-\mathbb E[X]$，但只能看到带噪样本方向 $\hat g(w_k)=w_k-x_k$。

3. Robbins-Monro：把“求固定点/求根”写成带噪迭代。

$$g(w)=0,\qquad w_{k+1}=w_k-\alpha_k g(w_k)$$
$$\hat g(w_k)=g(w_k)+\eta_k,\qquad w_{k+1}=w_k-\alpha_k\hat g(w_k)$$
$$\text{Robbins-Monro:}\qquad w_{k+1}=w_k-a_k\tilde g(w_k,\eta_k)$$
$$\sum_{k=1}^{\infty}\alpha_k=\infty,\qquad \sum_{k=1}^{\infty}\alpha_k^2<\infty$$
接下一步：Bellman 方程也可以看成“当前值 = 某个 target”的固定点；TD 就是用样本 target 给出带噪方向。

4. SGD：把优化里的真实期望梯度换成单样本梯度。

$$J(w)=\mathbb E[f(w,X)],\qquad \nabla_w J(w)=\mathbb E[\nabla_w f(w,X)]$$
$$w_{k+1}=w_k-\alpha_k\nabla_w f(w_k,x_k)$$
$$ \underbrace{\nabla_w f(w_k,x_k)}_{\hat g(w_k)} = \underbrace{\mathbb E[\nabla_w f(w_k,X)]}_{g(w_k)} + \underbrace{\left(\nabla_w f(w_k,x_k)-\mathbb E[\nabla_w f(w_k,X)]\right)}_{\eta_k} $$
读法：SGD 是 RM 用在 $\nabla_wJ(w)=0$ 上；均值估计也是 SGD 的特例，因为 $\nabla_w\frac12(w-X)^2=w-X$。

5. Dvoretzky：把收敛证明变成“误差递推”问题。

$$\Delta_{k+1}=(1-\alpha_k)\Delta_k+\beta_k\eta_k$$
$$\text{旧误差被 }(1-\alpha_k)\text{ 压小，噪声项 }\beta_k\eta_k\text{ 随步长变小}$$
定位：Dvoretzky 不是新算法，而是证明工具。只要某个算法的误差能写成这个模板，就可以讨论误差是否趋近 0。

6. TD(0)：把 Bellman 期望 target 换成一步样本 target。

$$v_\pi(s)=\mathbb E_\pi[R_{t+1}+\gamma v_\pi(S_{t+1})\mid S_t=s]$$
$$\underbrace{\mathbb E_\pi[R_{t+1}+\gamma v_\pi(S_{t+1})\mid S_t=s_t]}_{\text{真实 Bellman 期望 target}} \approx \underbrace{r_{t+1}+\gamma v_t(s_{t+1})}_{\text{一步样本 TD target}}$$
$$\delta_t=r_{t+1}+\gamma v_t(s_{t+1})-v_t(s_t)$$
$$v_{t+1}(s_t)=v_t(s_t)+\alpha_t\delta_t$$
对应 Ch6：$x_k$ 换成 TD target，$w_k$ 换成当前 $v_t(s_t)$，修正量就是 target - 当前估计。

7. Sarsa：把状态值 TD 推到动作值 TD。

$$q_\pi(s,a)=\mathbb E_\pi[R_{t+1}+\gamma q_\pi(S_{t+1},A_{t+1})\mid S_t=s,A_t=a]$$
$$\bar q_t^{\text{Sarsa}}=r_{t+1}+\gamma q_t(s_{t+1},a_{t+1})$$
$$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t[\bar q_t^{\text{Sarsa}}-q_t(s_t,a_t)]$$
关键：$a_{t+1}$ 是当前策略实际采样出来的动作，所以 Sarsa 学的是当前采样策略自己的 $q_\pi$，是 on-policy。

8. n-step Sarsa：真实展开几步，再接估计尾巴。

$$\bar q_t^{(n)} = r_{t+1} +\gamma r_{t+2} +\cdots +\gamma^{n-1}r_{t+n} +\gamma^n q_t(s_{t+n},a_{t+n})$$
$$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t[\bar q_t^{(n)}-q_t(s_t,a_t)]$$
读法：$n=1$ 是 Sarsa，$n\to\infty$ 接近 MC；它调的是 bias / variance 和更新延迟。

9. Expected Sarsa：不采下一动作，先把动作随机性平均掉。

$$\bar q_t^{\text{Expected}} = r_{t+1}+\gamma\sum_{a'}\pi(a'\mid s_{t+1})q_t(s_{t+1},a')$$
$$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t[\bar q_t^{\text{Expected}}-q_t(s_t,a_t)]$$
读法：Sarsa 抽一个 $a_{t+1}$；Expected Sarsa 对所有 $a'$ 按策略概率加权，通常方差更低。

10. Q-learning：target 从“当前策略会怎样”换成“最优会怎样”。

$$q^*(s,a)=\mathbb E[R_{t+1}+\gamma\max_{a'}q^*(S_{t+1},a')\mid S_t=s,A_t=a]$$
$$\bar q_t^{\text{Q}}=r_{t+1}+\gamma\max_{a'}q_t(s_{t+1},a')$$
$$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t[\bar q_t^{\text{Q}}-q_t(s_t,a_t)]$$
关键：Q-learning 不用实际采到的 $a_{t+1}$，而是枚举候选动作 $a'$ 后取最大；它的 target 指向 greedy 目标策略，所以本质 off-policy。

Ch6 关键公式完整表

主题关键公式一句话读法
一般形式 $$w_{k+1}=w_k-\alpha_k g(w_k)$$ $$\hat g(w_k)=g(w_k)+\eta_k,\qquad w_{k+1}=w_k-\alpha_k\hat g(w_k)$$ 理想时直接沿 $g$ 走；现实中只能沿带噪 $\hat g$ 走。
Robbins-Monro $$w_{k+1}=w_k-a_k\tilde g(w_k,\eta_k)$$ 最外层框架：用带噪观测求 $g(w)=0$。
步长条件 $$\sum_{k=1}^{\infty}a_k=\infty,\qquad \sum_{k=1}^{\infty}a_k^2<\infty$$ 总路程要够长，噪声平方影响要可控。
增量均值 $$w_{k+1}=w_k+\alpha_k(x_k-w_k)=w_k-\alpha_k(w_k-x_k)$$ $$\underbrace{w_k-x_k}_{\hat g(w_k)} = \underbrace{(w_k-\mathbb E[X])}_{g(w_k)} + \underbrace{(\mathbb E[X]-x_k)}_{\eta_k}$$ 样本把估计往自己方向拉；它也是带噪求根。
SGD $$w_{k+1}=w_k-\alpha_k\nabla_w f(w_k,x_k)$$ $$\underbrace{\nabla_w f(w_k,x_k)}_{\hat g(w_k)} = \underbrace{\mathbb E[\nabla_w f(w_k,X)]}_{g(w_k)} + \underbrace{\left(\nabla_w f(w_k,x_k)-\mathbb E[\nabla_w f(w_k,X)]\right)}_{\eta_k}$$ 单样本梯度替代真实期望梯度。
Dvoretzky $$\Delta_{k+1}=(1-\alpha_k)\Delta_k+\beta_k\eta_k$$ 证明工具：看误差如何被压缩、噪声如何变小。
BGD / SGD / MBGD $$\text{BGD: }w_{k+1}=w_k-\alpha_k\frac1n\sum_{i=1}^n\nabla f(w_k,x_i)$$ $$\text{SGD: }w_{k+1}=w_k-\alpha_k\nabla f(w_k,x_k)$$ $$\text{MBGD: }w_{k+1}=w_k-\alpha_k\frac1m\sum_{i\in B_k}\nabla f(w_k,x_i)$$ 每步用多少样本估梯度：全部、一个、小批量。

Ch7 关键公式完整表

主题关键公式一句话读法
TD(0) prediction $$\delta_t=r_{t+1}+\gamma v_t(s_{t+1})-v_t(s_t)$$ $$v_{t+1}(s_t)=v_t(s_t)+\alpha_t\delta_t$$ 用一步样本 target 逼近 $v_\pi$。
Sarsa $$\delta_t=r_{t+1}+\gamma q_t(s_{t+1},a_{t+1})-q_t(s_t,a_t)$$ $$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t\delta_t$$ 五元组 $(s_t,a_t,r_{t+1},s_{t+1},a_{t+1})$；on-policy。
Expected Sarsa $$\bar q_t=r_{t+1}+\gamma\sum_{a'}\pi(a'|s_{t+1})q_t(s_{t+1},a')$$ $$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t[\bar q_t-q_t(s_t,a_t)]$$ 把下一动作这层随机性先按策略平均掉。
$n$-step Sarsa $$\bar q_t^{(n)}=r_{t+1}+\gamma r_{t+2}+\cdots+\gamma^{n-1}r_{t+n}+\gamma^n q_t(s_{t+n},a_{t+n})$$ $$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t[\bar q_t^{(n)}-q_t(s_t,a_t)]$$ $n=1$ 是 Sarsa，$n\to\infty$ 接近 MC。
Q-learning $$\delta_t=r_{t+1}+\gamma\max_{a'}q_t(s_{t+1},a')-q_t(s_t,a_t)$$ $$q_{t+1}(s_t,a_t)=q_t(s_t,a_t)+\alpha_t\delta_t$$ 直接朝 Bellman optimality target 靠；本质 off-policy。
$\epsilon$-greedy 改进 $$\pi(a|s)= \begin{cases} 1-\epsilon+\epsilon/|\mathcal A(s)|,& a=\arg\max_b q(s,b)\\ \epsilon/|\mathcal A(s)|,& \text{otherwise} \end{cases}$$ 保留探索，同时偏向当前估计最好的动作。
离线 Q-learning $$\mathcal D=\{(s_i,a_i,r_i,s'_i)\}_{i=1}^N$$ $$q(s_i,a_i)\leftarrow q(s_i,a_i)+\alpha\big[r_i+\gamma\max_{a'}q(s'_i,a')-q(s_i,a_i)\big]$$ offline 说的是先固定数据集再训练，不是 off-policy 的同义词。

易混点速记

易混点正确读法
“样本 target” 是最终目标吗？不是。单次 target 有噪声，反复更新后想逼近的是 Bellman 方程的固定点。
Sarsa 和 Q-learning 只差一个 max 吗？公式上差在 target；含义上差在目标策略。Sarsa 学当前策略，Q-learning 朝最优 greedy 目标学。
on-policy / off-policy 等于 online / offline 吗？不等于。前者问采样策略和目标策略关系，后者问数据是一边来一边用，还是先固定一批再训练。
Ch6 的步长条件为什么重要？$\sum\alpha_k=\infty$ 保证能走到目标附近；$\sum\alpha_k^2<\infty$ 保证噪声累计影响被压下去。
总洞见
Ch6 负责回答“为什么可以用带噪样本一点点修正估计”，Ch7 负责回答“Bellman target 的样本版本到底长什么样”。把两章放一起看，TD、Sarsa、Q-learning 就不是一堆孤立公式，而是同一个随机近似母式下更换 target 的几个实例。
