一条公式链

1. Ch8 的出发点：表格价值变成参数函数。

$$\hat v(s,w)\approx v_\pi(s),\qquad \hat q(s,a,w)\approx q_\pi(s,a)\ \text{或}\ q^*(s,a)$$
$$\text{linear value:}\qquad \hat v(s,w)=\phi^T(s)w,\qquad \nabla_w\hat v(s,w)=\phi(s)$$
接下一步：表格法改一个格子；函数近似改共享参数 $w$，所以每次更新都会通过特征影响一片状态或动作。

2. 状态值函数近似：先像监督学习一样拟合 target。

$$\ell_t(w)=\frac12\big(y_t-\hat v(s_t,w)\big)^2$$
$$w_{t+1}=w_t+\alpha_t\big(y_t-\hat v(s_t,w_t)\big)\nabla_w\hat v(s_t,w_t)$$
$$ y_t= \begin{cases} G_t, & \text{MC return}\\ r_{t+1}+\gamma\hat v(s_{t+1},w_t), & \text{TD target} \end{cases} $$
读法：真实标签 $v_\pi(s_t)$ 看不见，所以用 MC return 或 TD target 代替。

3. 线性 TD：TD target + 线性特征，得到 TD-Linear。

$$\delta_t=r_{t+1}+\gamma\hat v(s_{t+1},w_t)-\hat v(s_t,w_t)$$
$$w_{t+1}=w_t+\alpha_t\delta_t\nabla_w\hat v(s_t,w_t)$$
$$w_{t+1}=w_t+\alpha_t\big[r_{t+1}+\gamma\phi^T(s_{t+1})w_t-\phi^T(s_t)w_t\big]\phi(s_t)$$
接下一步：TD-Linear 不是直接最小化真实误差，而是收敛到投影 Bellman 方程的固定点。

4. TD-Linear 的理论固定点：从随机更新到线性方程。

$$\mathbb E[\Delta w]\propto b-Aw,\qquad Aw=b,\qquad w^*=A^{-1}b$$
$$A=\Phi^TD(I-\gamma P_\pi)\Phi,\qquad b=\Phi^TDr_\pi$$
$$\Phi w=M T_\pi(\Phi w),\qquad J_{PBE}(w)=\|\hat v(w)-M T_\pi\hat v(w)\|_D^2$$
读法：线性空间表达不了所有真实价值时，Bellman backup 后要投影回可表示空间；TD-Linear 找这个投影后的固定点。

5. LSTD：不一步步推参数，而是直接估方程。

$$\hat A_t=\sum_{k=0}^{t-1}\phi(s_k)\big(\phi(s_k)-\gamma\phi(s_{k+1})\big)^T$$
$$\hat b_t=\sum_{k=0}^{t-1}r_{k+1}\phi(s_k),\qquad w_t=\hat A_t^{-1}\hat b_t$$
读法：LSTD 和 TD-Linear 的 target 没变，变的是求解方式：直接从样本估出 $A,b$ 再解线性方程。

6. 动作值函数近似：把输入从 $s$ 扩成 $(s,a)$。

$$\ell_t^q(w)=\frac12\big(y_t^q-\hat q(s_t,a_t,w)\big)^2$$
$$w_{t+1}=w_t+\alpha_t\big(y_t^q-\hat q(s_t,a_t,w_t)\big)\nabla_w\hat q(s_t,a_t,w_t)$$
$$ y_t^q= \begin{cases} r_{t+1}+\gamma\hat q(s_{t+1},a_{t+1},w_t), & \text{Sarsa-FA}\\ r_{t+1}+\gamma\max_{a'}\hat q(s_{t+1},a',w_t), & \text{Q-learning-FA} \end{cases} $$
关键：这不是换掉 $w$，而是用同一个平方误差模板拟合动作值 target。

7. DQN：把 Q-learning-FA 变成神经网络训练流程。

$$y_T=r+\gamma\max_{a'}\hat q(s',a',w_T)$$
$$L_{\text{DQN}}(w)=\frac1B\sum_{i=1}^{B}\big(y_{T,i}-\hat q(s_i,a_i,w)\big)^2$$
$$w_T\leftarrow w\quad\text{every }C\text{ updates},\qquad (s,a,r,s')\sim\mathcal B$$
读法：target network 固定标签，experience replay 打散时间相关性；DQN 的 loss 小不等于真实 value error 小。

8. Ch9 的转向：不只让价值函数参数化，策略本身也参数化。

$$\pi(a|s,\theta),\qquad \theta^*\in\arg\max_\theta J(\theta)$$
$$\theta_{t+1}=\theta_t+\alpha\nabla_\theta J(\theta_t)$$
$$\pi(a|s,\theta)=\frac{e^{h(s,a,\theta)}}{\sum_{a'}e^{h(s,a',\theta)}}$$
接下一步：要更新 $\theta$，先要把“策略好不好”压成一个标量 $J(\theta)$。

9. 策略目标 $J(\theta)$：就是把状态价值按任务分布平均。

$$J(\theta)=\mathbb E_{\pi_\theta}\left[\sum_{t=0}^{\infty}\gamma^tR_{t+1}\right]$$
$$J(\theta)=\sum_s\rho(s)v_{\pi_\theta}(s)=\mathbb E_{S_0\sim\rho}[v_{\pi_\theta}(S_0)]$$
$$\bar v_\pi=\sum_s d(s)v_\pi(s),\qquad \bar r_\pi=\sum_s d_\pi(s)r_\pi(s),\qquad \bar r_\pi=(1-\gamma)\bar v_\pi$$
读法：$v_\pi(s)$ 是指定起点的价值；$J(\theta)$ 是按任务起点或访问分布平均后的策略总分。

10. Policy gradient theorem：把长期目标梯度改写成可采样项。

$$\nabla_\theta J(\theta)=\sum_s\eta(s)\sum_a\nabla_\theta\pi(a|s,\theta)q_\pi(s,a)$$
$$\nabla_\theta\pi(a|s,\theta)=\pi(a|s,\theta)\nabla_\theta\ln\pi(a|s,\theta)$$
$$\nabla_\theta J(\theta)=\mathbb E_{S\sim\eta,A\sim\pi}\big[\nabla_\theta\ln\pi(A|S,\theta)q_\pi(S,A)\big]$$
读法：哪个动作的 $q_\pi$ 高，就把它在该状态下的 log probability 往上推；$q_\pi$ 低或为负，就往下压。

11. REINFORCE：用完整回报估计 $q_\pi(s_t,a_t)$。

$$G_t=\sum_{k=t+1}^{T}\gamma^{k-t-1}r_k$$
$$q_\pi(s_t,a_t)\approx G_t$$
$$\theta\leftarrow\theta+\alpha G_t\nabla_\theta\ln\pi(a_t|s_t,\theta)$$
读法：REINFORCE 是 on-policy Monte Carlo policy gradient：不自举，方差高；下一章 actor-critic 会用 critic 降方差。

Ch8 关键公式完整表

主题关键公式一句话读法
真实价值误差$$J_E(w)=\|\hat v(w)-v_\pi\|_D^2$$最直观，但依赖未知真值 $v_\pi$。
状态值母式$$w_{t+1}=w_t+\alpha_t(y_t-\hat v(s_t,w_t))\nabla_w\hat v(s_t,w_t)$$函数近似就是拟合可采样 target。
TD-FA$$w_{t+1}=w_t+\alpha_t[r_{t+1}+\gamma\hat v(s_{t+1},w_t)-\hat v(s_t,w_t)]\nabla_w\hat v(s_t,w_t)$$用 TD target 拟合状态值。
线性价值$$\hat v(s,w)=\phi^T(s)w,\qquad \nabla_w\hat v(s,w)=\phi(s)$$特征和参数内积。
TD-Linear$$w_{t+1}=w_t+\alpha_t[r_{t+1}+\gamma\phi^T(s_{t+1})w_t-\phi^T(s_t)w_t]\phi(s_t)$$表格 TD 是 one-hot 特征的特例。
投影 Bellman 方程$$\Phi w=M T_\pi(\Phi w),\qquad J_{PBE}(w)=\|\hat v(w)-M T_\pi\hat v(w)\|_D^2$$TD-Linear 对应投影后的 Bellman 固定点。
线性固定点$$A=\Phi^TD(I-\gamma P_\pi)\Phi,\quad b=\Phi^TDr_\pi,\quad w^*=A^{-1}b$$平均更新方向为 $b-Aw$。
LSTD$$\hat A_t=\sum_{k=0}^{t-1}\phi(s_k)(\phi(s_k)-\gamma\phi(s_{k+1}))^T,\quad \hat b_t=\sum_{k=0}^{t-1}r_{k+1}\phi(s_k),\quad w_t=\hat A_t^{-1}\hat b_t$$样本效率高，但矩阵代价大。
Sarsa-FA$$w_{t+1}=w_t+\alpha_t[r_{t+1}+\gamma\hat q(s_{t+1},a_{t+1},w_t)-\hat q(s_t,a_t,w_t)]\nabla_w\hat q(s_t,a_t,w_t)$$动作值 on-policy 函数近似。
Q-learning-FA$$w_{t+1}=w_t+\alpha_t[r_{t+1}+\gamma\max_{a'}\hat q(s_{t+1},a',w_t)-\hat q(s_t,a_t,w_t)]\nabla_w\hat q(s_t,a_t,w_t)$$动作值最优 target；本步 semi-gradient。
DQN$$y_T=r+\gamma\max_{a'}\hat q(s',a',w_T),\qquad \min_w\frac1B\sum_i(y_{T,i}-\hat q(s_i,a_i,w))^2$$Q-learning-FA + 神经网络 + 目标网络 + 经验回放。

Ch9 关键公式完整表

主题关键公式一句话读法
策略函数$$\pi(a|s,\theta),\qquad \theta^*\in\arg\max_\theta J(\theta)$$直接学习“怎么行动”。
梯度上升$$\theta_{t+1}=\theta_t+\alpha\nabla_\theta J(\theta_t)$$第 6 章 SGD 是下降；这里最大化回报，所以是上升。
折扣回报目标$$J(\theta)=\mathbb E_{\pi_\theta}\left[\sum_{t=0}^{\infty}\gamma^tR_{t+1}\right]=\sum_s\rho(s)v_{\pi_\theta}(s)$$策略总分是状态值的初始分布平均。
平均状态价值$$\bar v_\pi=\sum_s d(s)v_\pi(s)=d^Tv_\pi$$按关心的状态分布加权。
平均奖励$$\bar r_\pi=\sum_s d_\pi(s)r_\pi(s),\qquad r_\pi(s)=\sum_a\pi(a|s,\theta)r(s,a)$$continuing task 常用。
平均奖励与平均价值$$\bar r_\pi=(1-\gamma)\bar v_\pi$$同一策略的两种指标可互相换算。
Log trick$$\nabla_\theta\pi(a|s,\theta)=\pi(a|s,\theta)\nabla_\theta\ln\pi(a|s,\theta)$$把“概率的梯度”变成“log 概率梯度”。
Policy gradient theorem$$\nabla_\theta J(\theta)=\mathbb E_{S\sim\eta,A\sim\pi}\big[\nabla_\theta\ln\pi(A|S,\theta)q_\pi(S,A)\big]$$策略梯度的核心形状。
Softmax policy$$\pi(a|s,\theta)=\frac{e^{h(s,a,\theta)}}{\sum_{a'}e^{h(s,a',\theta)}}$$保证动作概率非负且和为 1。
REINFORCE$$\theta\leftarrow\theta+\alpha G_t\nabla_\theta\ln\pi(a_t|s_t,\theta),\qquad G_t=\sum_{k=t+1}^{T}\gamma^{k-t-1}r_k$$用 MC return 替代 $q_\pi(s_t,a_t)$。
REINFORCE 展开读法$$\nabla_\theta\ln\pi(a_t|s_t,\theta)=\frac{\nabla_\theta\pi(a_t|s_t,\theta)}{\pi(a_t|s_t,\theta)}$$高回报动作会被提高概率；低回报动作被压低概率。

易混点速记

易混点正确读法
Ch8 的 loss 为 0 是否等于价值准确？不一定。DQN loss 只是在 replay buffer 样本上小，未覆盖状态动作仍可能错。
TD-Linear 是最小化真实价值误差吗？不是直接最小化 $\|\hat v-v_\pi\|_D^2$，而是对应 projected Bellman fixed point。
Q-learning-FA 和 DQN 是什么关系？DQN 是神经网络版 Q-learning-FA 加 target network 和 replay buffer。
$J(\theta)$ 和 $v_\pi(s)$ 有什么区别？$v_\pi(s)$ 指定起点；$J(\theta)$ 是按初始状态分布或访问分布平均后的策略总分。
Policy gradient 是不是不用价值？不是。梯度里仍有 $q_\pi(s,a)$；只是价值服务于更新策略，而不是先学价值再 greedy。
REINFORCE 和 TD/DQN target 差别？REINFORCE 用完整后续回报 $G_t$，不自举，方差高；TD/DQN 用一步 bootstrap target。
总洞见
Ch8 把第 7 章的表格价值更新推广成参数更新：样本告诉价值函数该往哪里拟合。Ch9 把“学价值再导出策略”的路线往前推进一步：直接让策略带参数，并用价值 $q_\pi$ 作为每个动作的信用权重来更新策略。两章合起来看，就是从 value parameter $w$ 走到 policy parameter $\theta$，也正好铺垫 Ch10 的 actor-critic：actor 学策略，critic 学价值。
